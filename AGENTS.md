# Instructions for coding agents

To author breadboard or schematic figures in this repo's style, follow
[skills/plattfig/SKILL.md](skills/plattfig/SKILL.md). The library is
`plattfig.py` at the repo root (pure Python, no dependencies); write
one spec script per figure, run it, then rasterize the SVG and inspect
it before calling the figure done.
